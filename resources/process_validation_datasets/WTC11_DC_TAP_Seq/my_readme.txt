WTC11 screen design files (rules in workflow/rules/sceptre_setup.smk).

- 220308_WTC11_Random_Screen_sgOpti-DC.design.txt: gRNA design. Also on the IGVF Data Portal (IGVFFI0580WJFK).
- ChosenGenes.AllRegions.bed: all targeted regions.
- ChosenGenes.DistalElements.bed: targeted distal elements.
- even_older_guide_targets.tsv: guide-to-target table before merging overlapping targets; used to define promoter target regions.
- wtc11_full_gene_set_use_real_w_ensemble_id.txt: targeted genes with Ensembl IDs.
- cell_ranger_output/: Cell Ranger outputs. Download from GEO GSE303901.
