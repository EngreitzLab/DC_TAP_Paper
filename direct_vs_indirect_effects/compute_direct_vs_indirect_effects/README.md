## Estimating indirect effects in CRISPR datasets

This snakemake workflow empirically computes indirect effects rates from CRISPR datasets analyzed
using sceptre and uses these to compute direct effect rates and the probability of CRISPR E-G pairs 
being the result of a direct effect (vs. indirect, trans-acting effects).

This analysis uses the K562 and WTC11 DC-TAP-seq screens from this study, plus other published
CRISPR enhancer perturbation screens re-analyzed as part of Gschwind et al., Nature 2026. Required
files from these datasets are downloaded by the workflow from Zenodo. To reproduce these analyses
refer to the following repositories:

Indirect and direct rates calculates as part of https://github.com/argschwind/ENCODE_CRISPR_data:
- Gasperini et al., 2019

Differential expression input generated by https://github.com/EngreitzLab/ENCODE_Test_Dataset_Analysis:
- Xie et al., 2019
- Klann et al., 2021
- Morris et al., 2023

### Existing results

Following computed results have been included in the repository:
- `results/direct_effect_models`: Estimated direct effect rates and direct effects rate models
- `results/cis_positive_hit_rates.tsv`: Distance-binned cis hit rates per dataset
- `results/trans_positive_hit_rates.tsv`: Estimated indirect effects rates per dataset

### Running the workflow

This snakemake workflow requires that snakemake and mamba (or conda) are installed and available (
see [snakemake documentation](https://snakemake.readthedocs.io/en/stable/getting_started/installation.html)
for installation instructions). Other dependencies managed by the workflow itself via conda
environments.

To run the workflow from end to end, run:
```
snakemake --use-conda -j1 -n  # -n = dryrun; remove to run workflow
```

This runs the workflow locally one rule at a time. For more efficient parallelization on for example
an HPC cluster use snakemake's your [executor plugin](https://snakemake.readthedocs.io/en/stable/executing/executors.html)
of choice.

### Generated output

This workflow generates all output used for direct vs. indirect effects analyses presented in the
manuscript. Scripts to perform analyses and generate figures are in `../../results` in the
subdirectories corresponding to figures.
